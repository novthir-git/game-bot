# game-bot

基于图像识别的安卓模拟器游戏自动化框架。

宿主环境：**MuMu 模拟器 12**，语言：**Python**，识别路线：**截图 + 模板匹配 / OCR**
（游戏画面由引擎渲染成单张 Canvas，取不到控件树，无法使用 uiautomator 路线）

## 目录结构

```
games/                     每个游戏一个独立目录，互不干扰
  my_garden_world/         我的花园世界
    README.md              游戏档案 + 自动化目标
    docs/analysis.md       玩法与自动化可行性分析
    config/                设备、游戏、任务配置
    templates/             模板图（按界面分目录）
    tasks/                 任务流程脚本
    logs/                  运行日志与失败截图（不入库）
```

## 使用边界

本仓库仅做 **单账号、基于截图识别的外部自动化**，用于替代重复点击。

不做也不接受以下用途：内存读写 / 注入 hook、绕过反作弊检测、多开刷号套取实物或现金奖励。
使用者需自行确认所自动化的游戏其用户协议是否允许，并自行承担账号风险。
