# 我的花园世界 (My Garden World)

治愈系种花模拟经营手游的自动化配置与任务流程。

> 详细的玩法拆解与自动化可行性分析见 [`docs/analysis.md`](docs/analysis.md)。
> **本目录内所有玩法数据均来自公开攻略，尚未在游戏内逐条核对**，实装前需要用截图校准。

## 动手前先确认

1. **游戏内「园艺机器人」**（解锁后可 1~2 小时自动循环）已经覆盖了哪些操作？
2. **MuMu 12 自带的按键录制回放**能不能直接解决花架循环？

若上述两者已覆盖大部分需求，本项目的价值应聚焦在它们做不到的部分：
跨系统条件判断（体力满了才种、双倍时段才卖）、活动轮转策略、异常恢复与断线重连。

## 重要前提

本游戏的核心卖点之一是**游戏内鲜花可兑换线下真实花束配送**，且据报道送花机制与「花园打理质量」挂钩。

因此本目录的自动化范围严格限定为：**单账号、替代自己的重复点击**。
**不实现**多开刷号、批量注册、以套取实物奖励为目标的任何流程。

另需知悉：该游戏在黑猫投诉累计近 700 条投诉，集中于虚假宣传、诱导消费与未成年人保护缺失，
并被《新浪财经》2 月游戏领域红黑榜列入黑榜。投入开发前建议先自行验证奖励是否真实兑现。

```
  tasks.yaml      任务开关、执行间隔、参数

  resources/      水车、珍珠采集点
tasks/            任务流程脚本（待实现）
logs/             运行日志与失败截图（不入库）
```
