## 2. 核心玩法循环

```
水滴(体力) → 播种 → 浇水 / 施肥 / 除虫 → 收花
                                          ↓
            金币 ← 花架售卖 / 居民订单 / 顾客订单 / 宫廷特供
                                          ↓
                          扩建花园 / 解锁稀有花种 / 插花 / 庭院装扮
```

**资源体系：** 水滴（体力，限制每日种植次数）、阳光、花蜜、珍珠、金币

**每日固定事项：**

- 领水车免费水滴 —— 有容量上限，**溢出即浪费**，需定时领取
- 花灵密令小屋日常任务 —— 完成后可手动领取 **100 体力**，零氪玩家主要体力来源
- 珍珠采集 —— **每 2 小时一次**
- 激励视频 —— 每日 1 次，激活 **4 小时全渠道双倍金币**（覆盖花架售卖、居民订单、顾客订单、宫廷特供）
- 好友互访 / 偷花
- 四大活动轮转：百花成蜜 → 花笺集芳 → 碎玉成瓶 → 莳花纪闻，前一个活动是后一个的蓄水池

**花架机制（自动化价值最高）：**
花架需上架 **135 次**，可利用「上架后 4 分钟下架再重新上架」的机制刷次数。
约合 9 小时纯点击循环，是本游戏最典型的体力活。

## 3. 技术评估

### 3.1 节奏慢 → 技术栈可大幅简化 ✅

种花是分钟级到小时级的等待，无实时反应需求。

**结论：不需要 scrcpy / minitouch / MuMu 原生 DLL。**
`adb exec-out screencap` + `adb shell input tap` 的 200~800ms 延迟方案完全够用。
高性能截图与低延迟触控属于过度设计，不在本项目第一阶段范围内。

### 3.2 官方已提供部分自动化 ⚠️

- 游戏内 **「园艺机器人」**：解锁后可设置 1~2 小时自动循环
- **MuMu 12 官方**发布过本游戏的多开 / 后台挂机 / 按键录制教程，模拟器自带操作录制回放

动手前应先评估这两者的覆盖范围。本项目的差异化价值应在于：
跨系统条件判断、活动轮转策略、异常恢复与断线重连——这些是录制回放做不到的。

### 3.3 主要技术难点

| 难点 | 说明 | 对策 |
|---|---|---|
| **激励视频广告** | 时长不定、关闭按钮位置随机、多为第三方 SDK 界面，可能跳出外部应用 | **不做**。每日仅 1 次 4 小时双倍，收益最低而实现成本最高 |
| **美术风格干扰匹配** | 水彩国风，低对比度、渐变背景、花朵摇曳动画、粒子特效 | 模板只截按钮上**高对比的图标 / 文字**区域，避开半透明面板；灰度化后阈值取 0.75~0.80 |
| **弹窗密集** | 活动、公告、礼包、签到、限时推送 | 状态机必须有「通用弹窗关闭器」兜底：识别右上角 ✕ → 点击空白 → 连点返回键回主界面 |
| **数值读取** | 艺术字带描边，通用 OCR 准确率有限且单次耗时数十至两百毫秒 | **不使用 OCR**。改用比色（按钮亮/灰）、模板匹配、进度条像素长度判定状态；确需读数字时用 0~9 数字模板逐位匹配。计数与计时一律由 bot 自行维护，不读屏 |
| **活动轮转** | 四大活动周期切换，界面完全不同 | 配置驱动的任务表，每个活动独立状态机模块，不硬编码 |
| **平台差异** | 小游戏版跑在微信 / 抖音宿主内，布局与分辨率不同 | 本项目只支持安卓 APK 版 |

## 4. 实施路线

1. 验证游戏内「园艺机器人」与 MuMu 按键录制的覆盖范围
2. 确认目标版本为安卓 APK 版
3. **第一阶段**（收益约占八成）：花架 4 分钟循环 ×135、珍珠 2 小时采集、水车定时领取
4. **第二阶段**：花灵密令小屋日常任务、订单提交、通用弹窗兜底
5. **暂不实现**：激励视频、四大活动轮转策略

## 5. 风险与边界

### 5.1 实物奖励使本游戏区别于普通种田游戏

游戏核心卖点之一是**游戏内鲜花可兑换线下真实花束配送**，
据报道送花机制不仅含随机规则，还与「花园打理质量」相关联。

这意味着自动化此游戏不等同于「自动化自己的重复劳动」，而带有从运营方获取实物的性质。

**本项目采用的边界：**

- ✅ 单账号，替代自己的重复点击 —— 实现。使用者自行承担用户协议与封号风险
- ❌ 多开刷号、批量账号、以套取实物奖励为目标的流程 —— **不实现**

### 5.2 该游戏自身存在显著争议

- 黑猫投诉累计**近 700 条**，集中于虚假宣传、诱导消费、未成年人保护缺失
- 有玩家反映充值上万元仍未收到承诺的真实鲜花
- 被《新浪财经》2 月黑猫投诉游戏领域红黑榜列入**黑榜**
- 有消费者反映从未玩过游戏却被扣款 1900 元，客服与 Apple 就退款责任互相推诿

**建议：投入开发前先自行验证奖励机制是否真实兑现，避免为无法兑现的奖励投入工程成本。**
